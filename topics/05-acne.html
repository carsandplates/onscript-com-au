🔴 Acne Vulgaris

NSW Pharmacist Practice Standards for Acne (NSW Health Authority, signed 5 August 2025) · Patient ≥12 yo · Mild acne only · Topical only
💡 Mild acne only = few comedones, pustules, papules; no scarring; lesions often on T-zone (forehead, nose, chin). Diagnosis requires comedones — if only pustules/papules without comedones, it's probably not acne. Pharmacist supplies up to 6 weeks therapy per consultation; review at 6 weeks. Topical clindamycin capped at 3 months total.

✅ Eligibility

  • Patient ≥12 years, physically present, informed clinical + financial consent
  • Diagnosis = acne vulgaris (comedones + pustules + papules)
  • Mild severity only (few lesions; no scarring; T-zone)
  • Effective contraception confirmed if patient of childbearing potential using a teratogenic topical
  • No RED flags below

🗣️ Counselling (must cover)

  • 6–8 weeks before judging effect — counsel patience and possible initial purge
  • Apply retinoid to whole affected area, not just spot lesions; thin layer NOCTE
  • Sun protection — SPF 30+ daily (retinoids cause photosensitivity)
  • BPO bleaches fabrics + hair — apply at clean time
  • Gentle non-comedogenic cleanser BD; avoid over-washing; non-comedogenic moisturiser
  • Avoid picking / squeezing (scarring risk)
  • Diet evidence weak — possible link with high-glycaemic foods + dairy
  • Effective contraception when using teratogenic agents

📋 Documentation + review

SOAP record per NSW Authority requirements. 6-week review mandatory. Adverse events → report to TGA via aems.tga.gov.au AND notify usual GP. Upload to My Health Record unless declined. Retain ≥7 years (or to age 25 if patient <18).

🎯 OSCE pearls

  • State age ≥12 + mild only aloud
  • Classify lesion morphology (comedonal vs inflammatory vs nodular)
  • Endocrine red flag screen in adult women (PCOS, hirsutism, irregular menses) → refer
  • Pregnancy + contraception screen
  • Set realistic timeline (6–8 weeks for visible effect)
  • "Topical clindamycin alone" = trap question — never as monotherapy
  • Mention TGA + GP notification if adverse event

⚠️ Pitfalls

  • Adapalene is NOT safe in pregnancy — all topical retinoids contraindicated
  • Don't supply oral antibiotic / oral isotretinoin — outside NSW pharmacist scope (refer)
  • "Just give them something" — no, document non-prescribing reasoning per When Not To Prescribe
  • Topical clindamycin monotherapy = resistance + ineffective
