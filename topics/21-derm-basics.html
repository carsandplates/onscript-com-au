🩺 Dermatology Basics — Morphology + Assessment

Foundation skill for NSW PATH-DERM services (shingles, impetigo, mild plaque psoriasis, atopic dermatitis flares, mild acne) and all skin presentations
💡 Framework: History → Morphology → Distribution → Severity → Red flags → Working diagnosis → Management or referral. Precision in lesion description improves diagnosis + handover.

🔬 Skin functions (clinically relevant)

  • Barrier (protection)
  • Immune surveillance
  • Thermoregulation
  • Sensation
  • Prevention of fluid loss
  • Vitamin D synthesis

All matter in: inflammation, infection, itch, pain.

✏️ How to describe a lesion (precision matters)

⛔ Bad: "a red rash on the arm"
✅ Good: "multiple erythematous scaly papules coalescing into plaques on the flexor forearm with excoriation"

Description domains

  1. Morphology (primary + secondary)
  2. Number (single / few / multiple / numerous)
  3. Distribution + symmetry
  4. Colour + border
  5. Surface (smooth / scaly / crusted / vesicular)
  6. Site
  7. Arrangement (discrete / grouped / annular)
  8. Symptoms (itch / pain / tenderness / asymptomatic)

📋 Focused dermatology history

Symptom onset / chronology

  • Onset (sudden / gradual)
  • Duration · evolution · spread
  • Itch, pain, burning, tenderness
  • Triggers / exposures (new products, foods, plants, drugs)
  • Previous episodes · previous treatment + response

Patient factors

  • Past skin disease · atopy (asthma, AR, food allergy) · family history
  • Medications + recent changes · pregnancy / lactation · immunosuppression · diabetes
  • Contact history · systemic symptoms (fever, weight loss, joint pain)

Template

  1. Patient concern in their own words
  2. Key symptom · timing · distribution + spread
  3. Severity (impact on sleep, daily activity)
  4. Triggers · self-treatment
  5. Red flags

👁️ Skin examination sequence

  1. Stand back — gestalt of patient (well vs unwell)
  2. Inspect lesions closely — describe morphology
  3. Assess distribution + extent (e.g. Body Surface Area — Rule of 9s for burns; rule of palm = ~1%)
  4. Palpate where appropriate (texture, tenderness, warmth, induration, fluctuance, depth, mobility)
  5. Look at hair, nails, mucosa if relevant
  6. Decide: within scope or refer

Preparation

  • Privacy, consent, dignity, good lighting, adequate exposure
  • Gloves if touching lesion, ruler/penlight, documentation template
  • First impressions: distressed / feverish / lethargic / laboured breathing / pain / toxic appearance

🔴 RED flags in skin presentations

  • Fever / systemic unwellness
  • Rapid progression
  • Painful widespread rash
  • Non-blanching rash (meningococcal sepsis, vasculitis, ITP)
  • Blistering (esp. mucosal involvement — SJS/TEN, pemphigus, EM)
  • Mucosal involvement (mouth, eye, genitals)
  • Ocular symptoms
  • Immunocompromised patient
  • Eczema herpeticum (punched-out vesicles + fever)
  • Unclear diagnosis in unwell patient

🟠 ORANGE (refer)

  • Unclear diagnosis (well patient)
  • Severe disease — extensive / sleep-disturbing / QoL-impacting
  • Inadequate response to optimal pharmacist treatment
  • Signs of bacterial superinfection (cellulitis, lymphangitis)
  • Suspected scabies / lice (refer for prescription)
  • Suspected malignant lesion (ABCDE — asymmetry, border, colour, diameter >6 mm, evolution)
  • Recurrent / chronic conditions

📋 Documentation template

  • Morphology (primary + secondary)
  • Site / distribution
  • Symptoms (pain, itch, systemic)
  • Extent (count, BSA)
  • Red flags absent / present (explicit list)
  • Impression
  • Plan
Example: "Multiple honey-coloured crusted erosions around nose + upper lip, localised, mildly tender, no surrounding cellulitis, afebrile."

⚠️ Common pitfalls (Canvas)

  • Describing colour but not morphology
  • Missing distribution
  • Not asking about pain
  • Not asking about systemic symptoms
  • Not checking medication history

🎯 OSCE pearls

  • Use precise morphology terms (papule, vesicle, plaque — not "spot/bump/rash")
  • Distribution always
  • ABCDE for melanoma screen if any pigmented lesion
  • Mucosal + ocular always screened
  • Red flag list verbalised
  • Document morphology + distribution + symptoms + impression + plan
