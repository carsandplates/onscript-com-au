📋 Pre-vaccination screening (mandatory)

  • Identity check + informed verbal consent (documented)
  • Age + eligibility (NIP vs private)
  • Allergy hx (esp. vaccine components, prior anaphylaxis)
  • Medical hx: immunocompromise, pregnancy, recent surgery/illness, splenectomy
  • Current acute illness (fever ≥38.5 °C → defer)
  • Medications (esp. immunosuppressants)
  • Recent other vaccines (≥4 week interval between live vaccines if not co-administered)
  • Bleeding disorder / anticoagulant
  • Recent blood product
  • Faint history

🚨 Anaphylaxis preparedness + management

Adrenaline auto-injector within reach at all times: EpiPen 300 μg ≥25 kg · EpiPen Jr 150 μg child 7.5–25 kg. Resuscitation, oxygen, IV access if trained. Phone 000. Stay with patient.

Recognition (≥2 systems)

SystemFeatures
SkinUrticaria, angioedema, flushing
RespiratoryStridor, wheeze, SOB
CardiovascularHypotension, pre-syncope, collapse
GIVomiting, cramps

Treatment (memorise sequence)

  1. Lay patient flat (legs elevated; recovery position if vomiting)
  2. Adrenaline IM 0.01 mg/kg (max 0.5 mg adult / 0.3 mg child <50 kg via syringe). EpiPen 300 μg ≥25 kg; EpiPen Jr 150 μg child 7.5–25 kg. Mid-anterolateral thigh.
  3. Call 000
  4. High-flow O₂
  5. Repeat adrenaline q5 min if no improvement
  6. Antihistamines + steroids = NOT routine in acute anaphylaxis per current ASCIA (don't treat hypotension/airway). Never delay adrenaline.

📋 Post-vaccination

  • Observe in pharmacy 15 minutes (some vaccines 30 min)
  • Provide written record (immunisation summary)
  • Report to Australian Immunisation Register (AIR) within 10 days
  • Adverse Event Following Immunisation (AEFI) reporting to TGA via SAEFVIC / state systems

💉 Injection technique

  • IM site: deltoid (adults), anterolateral thigh (infants)
  • 23 G (25 mm) IM standard for adult; 25 G acceptable for thin deltoid / infant thigh; subcut 25–26 G
  • 90° angle, no aspiration needed (AIH)
  • Subcut for some (MMR, varicella, JE, yellow fever) — 25–26 G, 45°
  • Cold chain log within 2–8 °C before administration

🗣️ Pre-vaccination counselling

  • Vaccine + brand + dose volume
  • Mechanism (briefly)
  • Expected SE (sore arm, fatigue, low-grade fever 24–48h)
  • Serious AE list (rare)
  • AIR documentation (mandatory)
  • Timeframes + follow-up doses

📋 Documentation

AIR — mandatory within 10 days · pharmacy clinical record · written record to patient. Maintain ≥7 years.

🎯 OSCE pearls

  • Consent + identity + 2 patient identifiers
  • Verbal screen for contraindications (allergies, current illness, pregnancy, immunocompromise)
  • Discuss expected SE + serious AEs
  • Site selection + injection technique narration
  • Anaphylaxis kit accessibility check explicit
  • 15-min observation stated
  • AIR documentation mention

💎 Pearls

  • Cold chain — log temperature twice daily; excursions = quarantine + manufacturer query
  • Multiple vaccines same visit OK — separate sites or same arm ≥2.5 cm apart
  • dTpa in pregnancy 20–32 weeks — protects neonate from pertussis via passive antibody
  • Influenza ≥65 — high-dose or adjuvanted (Fluad Quad)
  • Egg-allergic flu vaccine — modern vaccines minimal egg; only severe anaphylaxis needs special handling
  • Live vaccines (MMR, varicella, zoster Zostavax, yellow fever, BCG, oral typhoid, rotavirus) — avoid pregnancy + immunocompromise
